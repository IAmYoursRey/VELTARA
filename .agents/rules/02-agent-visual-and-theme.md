# Rule: Standar Visual AI Agent & Theme Architecture

## 1. Filosofi Desain
- **Bebas dari AI Generic Slop**: Dilarang menggunakan layout klise, gradasi ungu-putih generik, atau font default tanpa karakter.
- **Atlas Design Language**: Utamakan tema berkarakter kuat, dense surface, AMOLED-black (`#000000`, `#09090b`, `#121214`), kontras tajam, border 1px halus (`rgba(255,255,255,0.08)`), dan aksen terukur.
- **Theme Factory**: Gunakan palet terkurasi (seperti *Ocean Depths*, *Modern Minimalist*, *Tech Innovation*, *Midnight Galaxy*) untuk memastikan harmoni visual.

## 2. Praktik Komponen Visual
- **Micro-interactions**: Gunakan transisi halus (150-250ms ease) untuk hover, active, dan loading states.
- **Tipografi**: Sandingkan header font berkarakter (misal sans geometris modern atau serif teknikal) dengan body font yang memiliki keterbacaan tinggi.
- **Accessibility & Contrast**: Rasio kontras teks minimal 4.5:1 (WCAG AA). Touch target minimal 44x44px.
